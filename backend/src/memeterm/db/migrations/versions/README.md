# Migrations

Alembic is configured but no baseline revision is committed yet — the
baseline gets autogenerated against a live Postgres so types (JSONB, ARRAY,
TIMESTAMPTZ, etc.) round-trip exactly as SQLAlchemy reads them back.

## Bootstrap (first time)

```bash
# 1. Bring up Postgres
docker compose -f infra/docker-compose.yml up -d postgres

# 2. Create the initial migration
cd backend
alembic -c alembic.ini revision --autogenerate -m "initial"

# 3. Apply it
alembic -c alembic.ini upgrade head
```

Commit the generated `versions/*_initial.py` file.

## Subsequent changes

1. Edit `memeterm/db/models.py`
2. `alembic -c alembic.ini revision --autogenerate -m "<what changed>"`
3. Review the generated SQL (especially constraint drops)
4. `alembic -c alembic.ini upgrade head`
5. Commit the new revision file
